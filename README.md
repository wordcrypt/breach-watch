# Breach Watch by WordCrypt

A public list of password and data breaches in the news, with plain-English summaries and what to do.

This list powers **[wordcrypt.com/breaches/](https://wordcrypt.com/breaches/)**. The data is in [`breaches.json`](breaches.json), newest first.

These are breaches at other companies, as reported by the companies themselves or by reputable news outlets. Each entry links to its source. WordCrypt is not affiliated with the companies or publications listed.

WordCrypt is a password app with no vault: passwords are never stored. Learn more at [wordcrypt.com](https://wordcrypt.com).
